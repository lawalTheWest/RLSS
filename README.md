# RLSS

This repository contains Android APK release files for RLSS.

## Download

Open the [Releases page](https://github.com/lawalTheWest/RLSS/releases) and download the APK attached to the release you want. Check the release notes and APK filename to choose the appropriate version for your device.

## Install

1. Download the APK to your Android device.
2. Open the downloaded file and review Android's installation prompt. If prompted, allow your browser or file manager to install apps from this source.
3. Complete the installation. To install a newer release over an existing copy, it must be signed with the same signing key.

Only install APKs from a source you trust. Android may show a warning because APKs installed outside Google Play are sideloaded.
